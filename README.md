## Axioma de Campo

$$R_c = \lambda \left( \frac{k}{\Phi + \varepsilon} \right)^{1/n}$$

| Termo | Papel |
|---|---|
| R_c | Escala crítica resultante |
| λ | Chave seletora de escala |
| k | Identidade do sistema |
| Φ | Fluxo de energia (Φ = Mc² em astrofísica) |
| ε | Energia do domínio observado |
| n | Expoente geométrico |

**Limite canônico:** com λ = 1, ε → 0 e n = 1, recupera a 5ª Forma, R_c = k/Φ —
também alcançada pelo axioma fundamental quando Va = 1.

## Escopos da Identidade k

- Buracos negros: k = c⁷ / (4 G² M)
- Espaço-tempo (2ª Forma): k = Φ · Va · R²
- Forma geral: identidade do sistema em análise

## Derivadas da 5ª Forma

**Dimensão**

$$R_c = \lambda \left( \frac{k}{\Phi} \right)^{1/n}$$

**Temporal**

$$R_c(t) = \lambda(t) \left( \frac{k}{\Phi^n t^q} \right)$$

**Estática**

$$R_c = \lambda \left( \frac{k}{\Phi^n} \right) \quad \text{com } \lambda \text{ constante}$$

**Energia**

$$R_c = \lambda \left( \frac{k}{\Phi + \varepsilon} \right)^{1/n}$$

## Formas Inversas

Fatores: F_z = 1 − 1/(1+z)², F_χ = 2 / (1 + √(1−χ²))
Termo auxiliar: A = √R − √(GM/c²) · sen θ

**21ª — Redshift inverso**

$$z = \left[ 1 - \frac{R_s}{F_{\chi} \cdot A^2} \right]^{-1/2} - 1$$

**22ª — Spin inverso**

$$\chi = \sqrt{ 1 - \left( \frac{2}{F_{\chi}} - 1 \right)^2 }$$

**23ª — Inclinação inversa**

$$\theta = \arcsin \left\{ \frac{\sqrt{R} - \sqrt{\dfrac{R_s}{F_z F_{\chi}}}}{\sqrt{\dfrac{GM}{c^2}}} \right\}$$


**24ª — Massa inversa**

$$M = \frac{R c^2}{ \left\{ G \left[ \sqrt{ \frac{2}{F_z \cdot F_{\chi}} } + \sin \theta \right]^2 \right\} }$$

| Forma | Isola | Depende de |
|---|---|---|
| 21ª | z | M, R, χ, θ |
| 22ª | χ | M, R, z, θ |
| 23ª | θ | M, R, z, χ |
| 24ª | M | R, z, χ, θ |
